# Plan: SDLProcessing.jl MVP - Bouncing Ball

This document outlines the implementation plan for creating a Minimum Viable Product (MVP) for `SDLProcessing.jl`. The goal is to create a simple sketch of a circle bouncing off the edges of the window, proving the viability of the core API design.

The plan is divided into actionable, self-contained sections.

## 1. Core Design Principles

Based on our discussion, the project will adhere to the following principles:

- **Sketch Structure:** Users define logic in `onsetup() do ... end` and `ondraw() do ... end` blocks. A `run_sketch()` function initiates and manages the application lifecycle.
- **State Management:** A single, global `const SKETCH` object, which is an instance of a `mutable struct`, serves as the single source of truth for both public sketch properties (e.g., window size, frame count) and internal library state (e.g., renderer context, style settings).
- **Drawing API:** All drawing functions (`background`, `fill`, `ellipse`, etc.) will be stateless. They will operate implicitly on the global `SKETCH` object.

## 2. Section 1: The `SKETCH` Object

This is the foundational element of the library.

**Action:** Create a `src/State.jl` file and define the `SketchState` struct and the global `SKETCH` object.

```julia
# src/State.jl

# A simple struct for RGBA color
struct Color
    r::UInt8
    g::UInt8
    b::UInt8
    a::UInt8
end

mutable struct SketchState
    # --- Public, read-only properties for the user ---
    width::Int
    height::Int
    frameCount::Int

    # --- Internal library properties (prefixed with _) ---
    _window::Ptr{Nothing}
    _renderer::Ptr{Nothing}
    _should_quit::Bool

    # --- Internal style properties ---
    _use_fill::Bool
    _fill_color::Color
    _use_stroke::Bool
    _stroke_color::Color
end

# Default constructor
function SketchState()
    return SketchState(
        0, 0, 0, # width, height, frameCount
        C_NULL, C_NULL, false, # _window, _renderer, _should_quit
        true, Color(255, 255, 255, 255), # _use_fill, _fill_color
        true, Color(0, 0, 0, 255)  # _use_stroke, _stroke_color
    )
end

# The global state object.
# It is a `const` so it cannot be reassigned, but its fields can be mutated.
const SKETCH = SketchState()
```

## 5. Section 4: MVP Implementation - Bouncing Ball

This is the target sketch we aim to create. It serves as the final goal and test case for the above sections.

**Action:** Create an example file `examples/bouncing_ball.jl`.

```julia
# examples/bouncing_ball.jl
using SDLProcessing

# --- Ball Object ---
mutable struct Ball
    x::Float64
    y::Float64
    vx::Float64 # Velocity x
    vy::Float64 # Velocity y
    radius::Float64
end

# Create a global instance of the ball for the sketch
ball = Ball(0, 0, 0, 0, 20)


# --- Sketch Definition ---

onsetup() do
    create_window(800, 600)

    # Initialize ball in the center with a random velocity
    ball.x = SKETCH.width / 2
    ball.y = SKETCH.height / 2
    ball.vx = (rand() - 0.5) * 10
    ball.vy = (rand() - 0.5) * 10

    stroke(color(255, 255, 255))
    fill(color(255, 0, 100))
end

ondraw() do
    background(color(0)) # Black background

    # 1. Update ball position
    ball.x += ball.vx
    ball.y += ball.vy

    # 2. Check for wall collisions and bounce
    if ball.x + ball.radius > SKETCH.width || ball.x - ball.radius < 0
        ball.vx *= -1
    end
    if ball.y + ball.radius > SKETCH.height || ball.y - ball.radius < 0
        ball.vy *= -1
    end

    # 3. Draw the ball
    ellipse(ball.x, ball.y, ball.radius * 2, ball.radius * 2)
end

# --- Run the Sketch ---
run_sketch()
```
